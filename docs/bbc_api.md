# bbconf API

`BedBaseAgent` is the entry point. Its `bed`, `bedset`, `objects`, `snapshot`, and `analysis_files` properties return the agents documented below.

::: bbconf.BedBaseAgent
    options:
      heading_level: 2
      members_order: source
